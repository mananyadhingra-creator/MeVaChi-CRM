# MeVaChi CRM

> **Enterprise Customer Relationship Management (CRM) System for MeVaChi Solutions**

A comprehensive web-based CRM developed to streamline customer relationship management, sales operations, proposal generation, project execution, installation tracking, and post-installation services for **MeVaChi Solutions**, an Indoor Air Quality (IAQ) company.

---

## About the Project

MeVaChi CRM is an enterprise web application built using **Flask**, **MySQL**, and **Bootstrap 5** to digitize and centralize business operations. The application enables different departments to collaborate efficiently while maintaining secure role-based access control.

The CRM manages the complete customer lifecycle—from lead generation and meetings to proposals, installations, invoicing, and customer service—through an intuitive dashboard and integrated workflow.

## Installation

Clone the repository:

```bash
git clone https://github.com/mananyadhingra-creator/MeVaChi-CRM.git
```

Navigate to the project directory:

```bash
cd MeVaChi-CRM
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Configure the MySQL database and update the database connection settings.

Run the application:

```bash
python app.py
```
